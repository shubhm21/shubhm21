## 🚀 Featured Projects

### 📦 [Supply Chain & Inventory Optimization](https://github.com/shubhm21/supply-chain-analytics)
**Technologies:** Python, SQL, scikit-learn, Power BI, Excel

End-to-end inventory analytics for a 150-SKU distributor (133K sales transactions, 110K daily inventory snapshots).
- Quantified **$2.34M of revenue lost to stockouts** and traced it to stale reorder points and unreliable suppliers.
- Back-tested four forecasting models; the ensemble reached **14% WAPE** on top products.
- Designed a safety-stock / reorder-point / EOQ policy that back-tests to **−88% stockouts with 4.8% less inventory**.
- Delivered an Excel planning workbook and a four-page Power BI dashboard.

### 💳 [Card Portfolio Risk Analysis](https://github.com/shubhm21/card-portfolio-analysis)
**Technologies:** Python, SQL, Power BI (DAX, Power Query)

Security and lifecycle analysis of 6,146 cards held by 2,000 clients.
- Built a star-schema SQL warehouse and 11 business queries using CTEs and window functions.
- Identified a **2,601-card reissue pipeline (~$37M of limit)** and 94 clients for priority outreach.
- Uncovered a data-migration artifact that was **understating security risk by ~7 points**.
- Masked card numbers and dropped CVVs at ingestion (privacy by design).

### 📊 Retail Sales & Customer Behavior Analysis
**Technologies:** Python, Pandas, SQL, Power BI, Excel

- Performed data cleaning and exploratory analysis.

- Identified customer purchasing patterns and retention opportunities.
- Designed interactive Power BI dashboards.
- Developed data-driven recommendations for customer engagement and revenue optimization.

### 🤖 Customer Sentiment Analysis Using NLP
